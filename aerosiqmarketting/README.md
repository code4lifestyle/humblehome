# Aerosiq Marketing

React marketing site for Aerosiq — a digital agency that builds brands that stand out.

## Stack

- React + Vite
- Tailwind CSS v4
- Three.js via `@react-three/fiber` + `@react-three/drei`
- Framer Motion

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
